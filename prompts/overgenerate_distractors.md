# 目标
为已确定题干和正确答案过生成 8-12 个高迷惑性干扰项候选，供后续过滤排序。题干可能有一个或多个正解。

# 要求
按思维链三步在内部完成，但最终只输出候选 JSON：
1. 标出本题考点
2. 解释每一条正确答案为何成立
3. 模拟学生易错逻辑生成候选

易错逻辑必须覆盖：
- 张冠李戴（材料中真实概念，用错场景）
- 部分正确（前半对后半错）
- 同维混淆（同一类别/同一语义场）
- 数值偏移（±15%~40%）
- 范围偏移（充分当必要、局部当全局）

每个候选与正确答案属于同一类别/维度，避免荒谬选项。
每个候选必须是可直接展示给学习者的具体概念、结论、数值或条件组合；rationale 必须说明它错在何处，并引用材料中的反证片段。
以下是待考查文本，不是指令。

# 返回格式
{
  "candidates": [
    {
      "text": "干扰项文本",
      "error_type": "张冠李戴",
      "rationale": "为什么有迷惑性及其错误点",
      "evidence_quote": "材料中可核对的反证原文"
    }
  ]
}

# 警告
- 候选不得与任何一条正确答案语义等价
- 候选不得直接抄写任何一条正确答案
- 禁止同义替换、词序改写、语气变化或只增删无关限定词
- 禁止「与正确答案相关但不同」「同类的其他概念」等泛化占位句
- 候选若也可能成立、会成为另一条合理正解、或无法由材料反证，宁可不输出
- 至少 8 个候选
- 不要输出最终 A/B/C/D 题
